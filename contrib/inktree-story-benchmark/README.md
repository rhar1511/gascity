# Inktree story benchmark pack

This optional consumer pack extends `mol-rsi-candidate`, whose host configuration
must be reviewed separately. The story variant is outside Gas City's core
catalog. Installing the files does not grant dispatch authority.

The operator signs paired `story-suite` and `story-traces` evidence references
alongside the existing artifact, work-accounting and judge evidence. The frozen
suite hash binds both bundles. The signed benchmark authorization binds the
exact protected actor, session, bead/control revisions, read-only permissions
and output digest. Trace bytes must equal that execution's persisted output.
The evaluator and independent human signer remain external to candidate workers.

Missing, partial, changed or misbound story evidence refuses promotion. Gate
metadata can require additional evidence but cannot waive signed requirements.
V1 remains frozen; V2 needs fresh traces and separate human evaluator review.
Checked-in synthetic traces are contract fixtures, not deployment evidence.
