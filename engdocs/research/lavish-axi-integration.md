# Lavish AXI × Gas City Workbench

Checked 2026-09-27 against lavish-axi commit [`40cafa2`](https://github.com/kunchenguid/lavish-axi/tree/40cafa206916cf21e4996158c347e58364d01559). **Recommendation:** optional, external HTML-artifact review only; do not make Lavish a Workbench runtime, task store, or embedded preview.

- **Architecture.** Lavish is a Node CLI plus detached local Express server. An agent writes an HTML file, `lavish-axi <file>` opens its browser review chrome, a sandboxed artifact iframe receives an annotation SDK, and `lavish-axi poll <file>` returns queued human feedback. Sessions are keyed by canonical file path; state is stored under `~/.lavish-axi` (or `LAVISH_AXI_STATE_DIR`). The browser/server also handle live reload, layout findings, image attachments, and Mermaid whiteboards. This is a separate feedback loop, not a Gas City session provider. [README](https://github.com/kunchenguid/lavish-axi/blob/40cafa206916cf21e4996158c347e58364d01559/README.md#how-it-works), [implementation invariants](https://github.com/kunchenguid/lavish-axi/blob/40cafa206916cf21e4996158c347e58364d01559/docs/invariants.md#architecture).
- **Install and surfaces.** Requires Node ≥22. The advertised path is `npx skills add kunchenguid/lavish-axi --skill lavish`, which runs `npx -y lavish-axi` on demand; direct CLI and source-build options also exist. Optional `setup hooks` adds agent SessionStart context; optional `setup plugin` targets VS Code/Cursor/Copilot CLI, not Codex. There is **no MCP server**. Programmatic touchpoints are the CLI (`open`, `poll`, `end`, `export`, `share`) and its local HTTP API; the latter is documented as Lavish's internal browser/CLI transport, not a stable integration API. [README installation/CLI](https://github.com/kunchenguid/lavish-axi/blob/40cafa206916cf21e4996158c347e58364d01559/README.md#quick-start), [package](https://github.com/kunchenguid/lavish-axi/blob/40cafa206916cf21e4996158c347e58364d01559/package.json), [AXI/plugin invariants](https://github.com/kunchenguid/lavish-axi/blob/40cafa206916cf21e4996158c347e58364d01559/docs/invariants.md#axi-integration).
- **Workbench fit.** Current Workbench derives its queue/attempts from Beads and Gas City sessions, and resolves previews from Bead `gc.preview_url` through a host allowlist; its preview is an iframe. Lavish's `/session/:key` sends `X-Frame-Options: DENY` and `frame-ancestors 'none'`, so its review UI cannot be dropped into that panel. Its path-keyed transcript must not become a second durable work record or substitute for Workbench attempt chat. [Workbench source](../../internal/api/dashboardspa/web/frontend/src/routes/Workbench.tsx), [preview policy](../../internal/api/dashboardspa/web/frontend/src/lib/workbenchPreview.ts), [Lavish frame policy](https://github.com/kunchenguid/lavish-axi/blob/40cafa206916cf21e4996158c347e58364d01559/src/server.js#L1387-L1407).
- **Security/privacy.** The server defaults to loopback, but automatically adds a Tailscale address when available; upstream warns that any non-loopback listener is unauthenticated and can serve local files to reachable clients. Host and Origin guards reduce rebinding/CSRF risk, not that exposure. Artifact JavaScript runs sandboxed in Lavish, but remote CDN/font URLs can still load; `export` leaves them as links. `share` explicitly uploads HTML to third-party ht-ml.app, **public by default**, and “unpublish” is not deletion. A self-hosted share API is possible. Release builds can include anonymous Umami telemetry when a website ID is configured; `LAVISH_AXI_TELEMETRY=0` opts out. [network policy](https://github.com/kunchenguid/lavish-axi/blob/40cafa206916cf21e4996158c347e58364d01559/README.md#how-it-works), [sharing](https://github.com/kunchenguid/lavish-axi/blob/40cafa206916cf21e4996158c347e58364d01559/README.md#how-it-works), [share backend contract](https://github.com/kunchenguid/lavish-axi/blob/40cafa206916cf21e4996158c347e58364d01559/docs/self-hosting-share.md), [telemetry source](https://github.com/kunchenguid/lavish-axi/blob/40cafa206916cf21e4996158c347e58364d01559/src/telemetry.js).
- **Maturity and minimum experiment.** At the inspected commit the package is MIT-licensed `0.1.79`, with a substantial `node:test` suite and release workflow; the pre-1.0 version and absence of a published embedding contract argue for a bounded trial, not a core dependency. For one explicit HTML-artifact attempt, let the agent/operator launch Lavish locally and open its returned URL in a separate tab. Keep Bead, attempt, and session lifecycle in Gas City; require explicit user action for sharing, avoid widening bind hosts, and pin/review the npm package before any managed deployment. Do not enable ambient hooks or automatic `poll` in Workbench until ownership, cancellation, and feedback-to-agent routing are designed and tested.
